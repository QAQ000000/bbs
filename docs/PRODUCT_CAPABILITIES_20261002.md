## 安装

`/setup` 四步：数据库与站点、管理员账号、邮件与安全、完成检查。`GET /api/v1/setup` 实查数据库与 schema，并返回 SMTP、Secure Cookie 状态，不返回数据库地址或凭据。服务必须先用部署 DSN 完成数据库连接/迁移才能启动；向导不更换运行中的数据库，也不提供浏览器编辑 DSN/SMTP 的入口。

步骤间保留输入；站点名、账号、邮箱及密码确认先校验，最终提交仍由后端校验。管理员密码只保存在当前组件内存，确认页不展示密码。一次提交创建管理员与站点；提交网络失败或 5xx 后先查询真实安装状态，查询也失败则禁止重复提交。成功显示完成页，已安装后再次进入会跳转登录入口（已有会话可能继续回首页）。

## 热门聚合

`GET /api/v1/home/popular` 先按查看者可见版块过滤，再排除已删/待审内容与封禁作者。

- 话题：近七天发布主题，按公开回复数、累计浏览数、主题 ID 倒序，最多五项。
- 作者：近七天公开发帖当前获赞数、发帖数、用户 ID 升序作同分排序，最多五项。
- 首页侧栏分别展示真实结果、空数据或接口不可用状态；手机沿用现有隐藏侧栏布局。

这是小型实时聚合，未做大数据量容量验收，不宣称达到此前持续负载目标。

## 周期榜

`GET /api/v1/leaderboard/points?period=balance|day|week|month&date=YYYY-MM-DD`，页面 `/leaderboard`。

余额榜保留原口径。周期榜以 Asia/Shanghai 自然日、周一开始的周、自然月，累计账本 `delta`，排除 `baseline`，包括扣减/退款/管理员调整；每榜 Top 100，同分按用户 ID。并非只累计正奖励或活跃度。

Worker 分别每小时刷新余额、当前/上一日、当前/上一周、当前/上一月快照。历史日期读取保留快照，不在 HTTP 请求内重算。当前周期延迟 65 分钟标记过期；已结束周期保留历史快照；快照缺失明确显示不可用。延迟入账可能更新上一周期，更早周期不保证持续回补。保留策略和时效字段见 [快照说明](ANALYTICS_SNAPSHOTS.md)。

## 邮件

后台详情从 `GET /api/v1/admin/email-jobs/{jobId}` 实时读取任务元数据，继续隐藏收件地址、正文、关联楼层和认证令牌。

`POST /api/v1/admin/email-jobs/{jobId}/cancel` 要求后台权限、`email.manage`、CSRF 及当前版本。只能取消待发送/失败任务，事务内清除密文、增加版本并写审计。发送中不可取消，已发送不可撤回。取消后不可重试；SMTP 未配置时也可取消。不撤销任务对应认证令牌。页面取消前确认，超时/冲突后先重新读取。

列表在服务器刷新后同步本地行与游标；详情请求通过请求序号忽略过期结果，关闭后不会因晚到响应重新弹出。
