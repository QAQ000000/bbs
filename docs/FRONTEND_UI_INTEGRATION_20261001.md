## 设计与真实契约的差异

- 设计包的 `/members/:id` 映射到 `/users/:id`；`/member/*`、`/auth/*`、`/content/new` 等演示路径不迁入当前导航。
- 手机首页的“全部、技术、问答、生活、公告”在包内是静态 span，未实现分类过滤。接入版继续提供真实的“综合、关注版块、关注的人”，使用同类胶囊样式。
- 首页不显示模拟热门作者、热门话题、点赞计数与签到奖励数。侧栏使用已有公开公告、统计、标签和有效快捷链接；标签不称为热门排名。
- 站点名使用后台配置，头像和封面使用真实资源。仅导入设计包的横幅 `img46.png` 为 `frontend/public/assets/design-20261001/home-banner.png`；模拟头像与主题配图不作为真实内容使用。
- 用户主页没有粉丝数、所在地、徽章集合的接口投影，因此只展示真实发帖/获赞、注册时间、等级及已佩戴称号。统计与列表沿用现有后端口径。
- 目录的模拟“关注成功”按钮改为进入真实版块详情；订阅操作继续由详情页处理。
- 手机保留实际分页入口，仅底栏提供全局发布入口；不迁入设计包的重复悬浮发布按钮。
- 404 与上游故障继续分开处理。关注状态未知时按钮不可操作；切换用户时关注按钮按查看者、目标用户和服务端状态重新挂载。

### 继续保留的契约差异

- 设计包独立投票/悬赏演示页映射为主题内真实组件；回复入口仍进入真实编辑器，不建立假提交入口。
- 签到没有未来七天奖励投影，不生成假日历；排行榜不加入模拟排名、日周榜切换或假分页。
- 认证页不添加没有后端支持的第三方登录或虚构社区人数；安装继续使用单步站点名/管理员表单，数据库参数仍由部署环境提供。
- 后台保留全部真实模块，而非只复制包中演示菜单；报表不提供没有接口的导出/重算；站点设置仍是版本化整体保存，分组导航不代表部分保存。
- 邮件收件人等不返回的敏感字段不补假值；会员、称号、经验与积分权限及预览发布、危险操作确认保留。
- 手机断点统一为 768px；页面内容比设计包更长时允许自然增高，表格在容器内滚动，不截断真实字段。

### 接入时修正的显示问题

- 私信无效会话提示采用明确的 CSS 优先级，防止手机隐藏会话区时连错误说明一并隐藏；会话编辑器按会话 ID 重置。
- 数字标签别名与 ID 路由歧义：统一 `tagPath`，纯数字 slug 使用 ID 链接；目录、侧栏、详情 canonical/分页及 sitemap 共用规则，非数字 slug 保留编码后的语义地址。
- 标签主题接口实际返回 `ThreadSummary[]`，修正原页面错误使用 `{threads, stickies}` 的读取方式，避免标签详情运行时崩溃。
- 到期但状态仍为 `published` 的投票，标题徽标与已有到期判断统一显示“已结束”；不改变投票接口或业务状态。
- 页头搜索文案改为“搜索主题”，与真实搜索契约一致；公共手机标题补齐标签、搜索、新建、编辑、签到与榜单。
